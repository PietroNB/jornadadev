# TCC - Cadastro de Tolerância (ZZ1)

Projeto desenvolvido para a Jornada DEV — TOTVS Paulista.

- **O que foi feito:** Criação da tabela customizada ZZ1 no Protheus e tela de cadastro automatizada.
- **Como rodar:** Compilar o arquivo `STTZZ1.PRW` e executar a User Function `U_STTZZ1()`.
